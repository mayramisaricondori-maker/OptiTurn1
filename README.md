# OptiTurn

## Descripción del proyecto

OptiTurn es una solución digital orientada a la gestión y optimización de reservas y turnos. 
El proyecto busca mejorar la organización de servicios mediante una interfaz intuitiva, permitiendo a los usuarios acceder a una experiencia rápida, ordenada y eficiente.

## Objetivo del proyecto

Desarrollar una plataforma digital que permita optimizar la gestión de turnos y reservas, mejorando la experiencia del usuario mediante un diseño responsive y una interfaz amigable.

## Tecnologías utilizadas

Las tecnologías utilizadas para el desarrollo del proyecto fueron:

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- Visual Studio Code
- Figma
