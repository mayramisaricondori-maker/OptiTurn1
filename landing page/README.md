# OptiTurn

## Descripción

OptiTurn es una plataforma inteligente que permite a los usuarios consultar el nivel de congestión en tiempo real, reservar turnos virtuales y recibir recomendaciones para optimizar su tiempo en bancos, hospitales, municipalidades y otros servicios.

---

## Objetivo

Reducir los tiempos de espera y mejorar la experiencia de los usuarios mediante una solución digital que optimiza la gestión de turnos y filas virtuales.

---

## Funcionalidades

- Consulta de congestión en tiempo real.
- Reserva de turnos virtuales.
- Alertas y notificaciones.
- Búsqueda de establecimientos.
- Visualización del historial de actividad.

---

## Instalación

1. Clonar el repositorio:

```bash
git clone https://github.com/mayramisaricondori-maker/OptiTurn1.git
```

2. Ingresar a la carpeta del proyecto:

```bash
cd OptiTurn1
```

3. Abrir el archivo `index.html` en el navegador.
